Longest Common Subsequence

把两个 String 的问题拆成两个 Prefix 的问题。每一步都展示：正在比较什么、读取哪些格、为什么这样计算。

示例：每个 String 最多 12 个字符；可以留空。
dp[i][j] = text1[:i] 与 text2[:j] 的 LCS 长度。
i / j 是 Prefix 长度，不是 String Index。比较的末尾字符是 text1[i−1] 与 text2[j−1]；LCS 不必在这两个末尾字符处结束。

最终答案

Initialization







只记三个依赖
1
初始化：第 0 行、第 0 列为 0。
任意 String 与 Empty String 的 LCS 长度都是 0。
2
末尾字符相同：左上 + 1。
dp[i][j] = dp[i−1][j−1] + 1
把相同字符接在两个更短 Prefix 的 LCS 后面。
3
末尾字符不同：max(上, 左)。
dp[i][j] = max(dp[i−1][j], dp[i][j−1])
分别尝试跳过一边的末尾字符，保留较长的结果。不是把两边都跳过。
Time: O(mn) · Space: O(mn)。这里先保留完整 DP Table，方便理解依赖关系。


对应代码
class Solution:
    def longestCommonSubsequence(
        self, text1: str, text2: str
    ) -> int:
        m, n = len(text1), len(text2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(
                        dp[i - 1][j], dp[i][j - 1]
                    )

        return dp[m][n]
