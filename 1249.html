读懂 cnt：两遍遍历中，它分别代表什么？

Pass 1：cnt 是扫描到目前为止，尚未匹配的 ( 数量；遇到 ( 加 1，保留一个 ) 时减 1。

Pass 2：cnt 是还需要删除的 ( 数量。条件 ch == '(' and cnt > 0 成立，就跳过这个字符并减 1。不 append 才是删除，减 1 只是更新数量。

为什么从右侧删？先删更靠后的 (，可以为前面的 ) 保留它需要的左括号。例如 ()( 若删第一个 (，会变成不合法的 )(。

不追踪具体配对：第二遍删除的是最右侧的若干个 (，不一定是第一遍匹配方式下剩余的那些位置。例如 (() 会删除中间的 (，保留的括号重新配对，得到 ()。题目允许任意最少删除后的合法答案。

Time：O(n)　Space：O(n)。这是被演示的 Python 算法的 Complexity；逐步快照演示会额外保存中间状态。
